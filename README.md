# DIO-Bernardo-EXCEL-IA-Planilha Vendas Xbox

Essa atividade foi feita a partir de uma planilha base, com informações de assinaturas do Xbox Game Pass. A ideia é organizar os dados e mostrar o faturamento de um jeito mais fácil de entender.

A planilha tem quatro abas:

Assets: cores, logos e outros elementos usados no visual.

Bases: dados das assinaturas, como tipo de plano, preço, renovação automática e passes adicionais.

Cálculos: perguntas sobre o faturamento, respondidas com tabelas dinâmicas.

Dashboard: painel que reúne as informações de forma visual.

O que eu mudei

Mantive a estrutura principal da atividade, mas fiz alguns ajustes na apresentação, como mudar certos títulos, reescrever as perguntas para ficarem mais claras e alterar alguns detalhes de cores e textos no dashboard.

Nos cálculos, deixei as perguntas de faturamento de acordo com o filtro trimestral que aparece nas tabelas. Os dados e os resultados foram mantidos.

O objetivo foi deixar a planilha organizada, fácil de consultar e com uma apresentação um pouco diferente do modelo, sem mudar o funcionamento dela.
